VRMアバター用デスクトップアプリ

WebカメラでVRMアバターを動かすアプリ

RusTuberVはWebカメラで取得した顔や手の動きをVRMアバターに反映させるデスクトップアプリです。NDIやSpout2を利用して背景が透明な映像をOBSへ送信できます。

01 / 主な機能

トラッキングとアバターの調整機能

01

顔と上半身・腕・手のトラッキング

Webカメラで取得した顔の向き、まばたき、視線、口の動きをアバターに反映します。さらに上半身・腕・手の追跡にも対応し、パソコン内蔵のカメラでも利用可能です。

02

VRM 0.xと1.0の読み込み

VRM 0.xおよび1.0のアバターを読み込むことができます。モデルに保存されたマテリアルや表情を使って表示します。

03

表情と画角の調整

キー操作で表情を切り替えることができます。また、アバターの左右反転や画角の調整にも対応しており、表情のキー割り当てはアバターごとに保存できます。

02 / 初期設定

アバターとWebカメラの設定

使用するVRMアバターとWebカメラを準備し、配布ZIPを展開したうえでアプリを起動します。

  1. 1

    アバターを選ぶ

    「VRMを読み込む…」ボタンから.vrmファイルを選びます。モデルの利用条件を確認して読み込みます。

    読み込みの手順 →
  2. 2

    カメラを選ぶ

    「入力カメラ」で使用するカメラを選び、顔を向けます。腕と手も追跡するときは、肩・肘・手首・手が映る位置にカメラを置きます。

    カメラの設定 →
  3. 3

    映り方を整える

    プレビュー上でマウスホイールを回すと拡大縮小できます。右ドラッグで位置を移動し、左ドラッグで向きを変更できます。

    画角・姿勢の調整 →

03 / OBSへの出力

OBSへの映像送信

背景が透明なアバター映像をOBSへ送信でき、OBS上でゲーム画面や背景画像と重ねて配信や録画に使えます。

プレビューで調整した構図が出力にも反映されます。音声はOBSでマイクを設定して取り込みます。

WINDOWS

Spout2 ↗

同じWindows PC上で動作するOBSへ映像を送信し、OBS Spout2 pluginを導入すれば背景が透明な映像を受け取れます。

Spout2の接続手順 →

同じPCや同一ネットワーク上のOBSへ映像を送信でき、WindowsとMacの両方で利用可能です。OBS側ではDistroAVと対応するNDI Runtimeを準備してください。
