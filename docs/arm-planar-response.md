# 腕の画面内移動への応答改善

## 変更の目的と範囲

頭に比べて腕が遅れて見える原因の一つは、手首125ms・肘150msの
二次平滑化である。時定数は目標へ到達するまでの時間ではなく、
従来の手首フィルターはステップ入力の90%へ約486msで到達する。

この変更は、肩基準・校正済み腕長単位で表された手首と肘の
左右／上下の位置応答を改善する第一段階とする。入力モデル、
観測の採用・消失・復帰、骨長、関節可動域、接触制約は既存のまま。
Hand Landmarkerの2D座標を位置追従へ使う変更は含まない。

## 実装

`arm_tracking_position.rs` の `ArmPositionSmoother` が、手首・肘それぞれの
位置応答を担当する。ECS、時計、入出力、追加依存は持たない。

- `planar_time_constant(distance, quiet_tau)` は採用済み目標と出力の
  XY距離から時定数を返す純粋関数。距離が腕長の5%以内では従来の
  時定数を保ち、5〜20%で滑らかに短縮し、20%以上では40msとする。
- この距離は動きの有効・無効を判定する閾値ではない。小さい動きも
  従来どおり追従し、停止や観測棄却のモードは追加しない。
- X/Yは同じ時定数を使う。Zは動きの大きさによらず従来の時定数を使い、
  奥行きノイズが肘の曲げ伸ばしへ伝わるのを引き続き抑える。
- `cascade_step(position, first, target, dt, tau)` は二つの一次遅れを
  直列にした系の、目標と時定数を保持した1ステップの厳密解。
  固定時定数では従来の臨界減衰と等価になる。
- 状態は二つの位置として保持する。時定数変更時に古い帯域の速度を
  引き継がない。各ステップの出力は以前の二つの位置と目標の凸結合で、
  静止状態からの一定目標へのステップで行き過ぎを発生させない。
- 手首と肘は独立した観測を追う。肘の目標を手首の中点や残差から
  作り直さず、既存の肘平面の安定化・回転速度制限をそのまま使う。
- 肩・胸郭、掌の回転、指の応答は変更しない。

現在のフィルターへの追加段ではなく、腕の位置フィルターの置き換えである。
大きな単発誤検出と意図した移動の区別は、引き続き既存の観測採用処理が担う。
動作中や停止直後のノイズが最終骨で増えないかは、下記の実機確認で評価する。

## 検証記録

基準ソース: `5f865a273a36f84e32051868436d80ee054d327c`。

Rust／PowerShellがない実行環境のため、以下は新旧の位置更新式を
Python／NumPyのfloat32へ転記した数値確認である。
Rustテストの実行結果やアプリの実測遅延を示すものではない。

60Hzで静止状態から目標を切り替えたときのフィルター単独の結果:

| 入力 | 到達点 | 従来 | 変更後 |
| --- | --- | ---: | ---: |
| 手首XYを腕長の40%移動 | 50% | 216.7ms | 83.3ms |
| 同上 | 90% | 500.0ms | 283.3ms |
| 肘XYを腕長の20%移動 | 50% | 266.7ms | 116.7ms |
| 同上 | 90% | 600.0ms | 433.3ms |

30／60／120Hzで次を確認した。

- 一定目標への大きなステップは単調に収束し、行き過ぎなし。
- 停止・反転の入力で、出力は観測範囲内に収まり、停止後に収束。
- 小さい複合ノイズに対する従来との差は、腕長単位で最大`9.6e-8`。
- 大きなXY移動中も、Z出力の従来との差は最大`9.8e-9`。
- 既存と同じ振幅・周波数の6座標の静止ノイズ評価では、2Hz以上の
  最大振幅比は約`0.287`で、既存の`0.35`未満を維持。
- 同相・逆相・異なる位相の複合ノイズで、入力に対する出力の
  エネルギー比とフレーム間変化のエネルギー比はともに1未満。
- 既存の`stationary_arm_noise.json`を位置フィルターへ入力した比較では、
  従来との差は最大`1.8e-7`。これは観測の前処理と最終骨を含む試験ではない。

Rust側には、静止応答の一致、XY移動中のZノイズ、時間応答、停止・反転、
ゼロ時間ステップの回帰テストを追加した。
既存の減衰・複数ノイズ・最終骨出力テストの判定値は変更していない。
「速い手と遅い手が必ず同じ割合で進む」テストは、今回の可変応答に合わせ、
「速い手を遅い手より鈍くしない」という目的の判定に変更した。

## Windowsで残っている確認

```powershell
.\tools\cargo-windows.ps1 -CargoArguments @('test', '--locked', '-p', 'vtuber-tracking', '-p', 'vtuber-avatar', '--lib', '-j', '1')
```

このテストで既存の静止・複合ノイズと最終骨出力を確認したうえで、同じ
カメラ動画・VRMによる前後比較を行う。確認対象は、手上げ、左右の手振り、
反転、停止、静止、腕の伸ばし切り、身体の前の横切り、遮蔽からの復帰。
肘・肩・掌の揺れを増やさず、動き始め・反転・停止の遅れが減ることを確認する。

既存の撮影時刻から適用時刻までの計測に加え、元動画と最終骨の動作の
時間差を見る。平滑化後の制御値だけを再生しても、このフィルター変更の
比較にはならない。フィルター単独の改善を、頭と腕の見た目の遅延が同等に
なったという結論へ置き換えない。
