# 上肢の関節座標と制約（Epic #248）

状態: 統合実装・確認中。Epic の完了記録ではない。

## 初期姿勢

利用者の指定により、2026-10-03から水平から80度下げ、鉛直から外側へ10度残す。
`ArmPoseProfile` の一つの値を初期表示・仮想腕・欠測復帰で共有する。
腕長0.5 mなら手首は肩から約0.087 m外側になる。これは衣服を含む全VRMへの
非貫通保証ではなく、#256 の表示形状と #257 の制約解決を通した手首位置を初期姿勢にする。
直線腕の解析初期値が衣服へ入る場合は、公開可動域内の肩3角・肘角の5点ずつの
格子から実行可能な初期値を選び、同じSQPで目標へ近づける。格子点は探索用で、
新しい人体係数ではない。受理したneutral FKを保存し、欠測時もその姿勢へ戻す。

## 肩の座標

`shoulder.rs` は骨localのEuler角ではなく、親の現在回転を一度だけ除いた
胸郭基準の回転を扱う。+Yが上、+Zが前、左の外側が+X。左右反射では
方向をpolar vector、肘屈曲軸をaxial vectorとして扱う。
restの上腕方向と固定肘軸から基準フレームを作り、非identityのbone restを
共役変換で保存する。neutralは上腕が下、90度曲げた肘の前腕が前を向く姿勢。

挙上面 p は外側0度・前方90度、挙上 e は真下0度・真上180度、軸回旋 a は
内旋を正とするglobe座標。側の符号 s を左+1・右-1として、neutralからの回転は
`Ry(-s*p) Rz(s*e) Ry(s*p) Ry(-s*a)`。
最初の3項を下向きベクトルからの最短swingとして計算し、残差twistから a を回収する。
ISBの反復軸3回転と比べ、最後の軸回転は挙上面の逆回転を含むため、a を
ISBの第3角へそのまま代入しない。この角度はthoracohumeralであり、
連成域は解いた肩甲帯との差分から別に評価する。通常VRMとCMUのclavicleには
独立した肩甲骨の姿勢がないため、この差分を個人のglenohumeral角の直接計測とは呼ばない。

統合版の範囲は、軸・offsetと同じMyoArm 93b0ca8の定義を採用する。
p=[-1.658,2.269] rad、e=[0,pi]、a=[-1.571,2.094] rad。MyoArmの
`shoulder1_r2_con_r` は挙上面の逆回転を結合し、本実装のglobe回転積と対応する。
Xu 2012が記載する旧Holzbaur版のa上限20度を、別版の軸へ混在させない。
MyoArmの範囲と後述CMUの連成領域を両方満たす必要があり、観測に応じて範囲を変更しない。
この定義域は全個人の生理的最大値ではない。
制約後に同じ固定骨長FKで肘/手首を再構成し、内外旋超過を前腕回旋へ転嫁しない。
観測・初期・仮想・復帰は同じ肩座標の制約を通る。

下向きの極では挙上面を `None` とし、方向だけから架空の面を測定しない。
正確な上向きの極では面とtwistの分離が一意でなく、変換結果を `None` として
既存の未解決姿勢の保持へ伝える。極の判定はf32精度に基づくもので、角度保持幅ではない。
経路の保持では極の plane を再観測せず関節座標を保持する。時間更新は後述。

## 胸郭入力（#250）

Poseの肩11/12と股関節23/24を同じseq/撮影時刻の観測に保持する。
肩中点から股関節中点への方向と肩の左右方向から直交基底を作る。
これは皮膚上の推定点による体幹proxyであり、ISBのIJ/C7/PX/T8骨指標ではない。
最初の信頼できるフレームをneutralとして保持し、既存の再校正操作で破棄する。
モデル交換では身体の校正を保持し、表示のフィルタ/欠測状態だけを初期化する。

肩中心は股関節中点に対する位置として復元できる形で残す。出力は校正時の
胸郭座標・肩幅に正規化した変位で、現在の胸郭回転で消去しない。
片肩の前出しと胸郭の回旋をこの4点だけで完全に分離できるわけではない。
肩甲帯のモデル適合では回転と肩中心が同じ入力に由来することを考慮する必要があり、
その利用側では後述の4点fitの残差と公開肩甲帯モデルを組み合わせる。

股関節の信頼度不足・画角外は胸郭欠測として既存LossBlendの保持/復帰へ渡す。
同じseqの描画tickでもrotation/shoulderの状態を進める。頭の角度を胸郭観測へ補完しない。
Pose追跡中はdirect poseの既存writerが胸郭を最上位の胸ボーンへ適用し、
首/頭には実際の親回転との差分だけを適用する。首/頭の既存の局所回転限界は維持する。
顔だけを使うモードは従来のbody distributionを使う。

## 手首 (#254)

Hand内のwrist→index/little MCP単位ベクトルの二等分線を長軸として追加した。
法線（軸性）と長軸（極性）は鏡像時の変換を分け、既存の描画tickフィルタ・
採用/欠測weightと一緒に保持する。PoseとHandの座標原点は混ぜない。

VRMのrest前腕長軸Y、掌法線から直交化したZ、X=Y×Zを前腕基準とする。
この基準に対するX/Zの回転をhandへ渡す。前腕は別の橈尺関節座標を持つ。
掌法線と長軸の両方を両腕ソルバーの目的に含め、位置と向きを同時に解く。
VRMの単一handでは手根骨二列を集約した2蝶番として扱い、独立した手首twistは
持たない。rest掌と前腕のずれをゼロと仮定しない。既存の単一writerから
rest相対deltaを適用する。

統合版では同じMyoArmの手首可動域（掌背屈±45°、橈屈10°/尺屈25°）を使用する。
左右で反転する掌法線基準のため掌背屈/前腕回旋の符号は反転し、橈尺屈は不変。
前腕と手首を含む関節状態を同時に解き、許容された経路をFKに渡す。
旧PalmRollFilter/WristFilterは撤去し、生の掌への後段の再一致は行わない。

## 肘と橈尺関節の VRM 写像 (#251、2026-10-04)

[MyoArmRight_v0.01、MyoHub 93b0ca8](https://github.com/MyoHub/myo_sim/blob/93b0ca8f4ec90c9899ee7f05fee561e9911da91b/myo_sim/models/arm/assets/myoarm_r_chain.xml)
の Apache-2.0 の軸と関節間 offset を使う。LICENSE と改変 NOTICE を残す。
元の +X 前方/+Y 上方/+Z 右外側をアプリ座標へ変換し、上腕長軸と肘軸の
直交成分が作る frame を VRM の不変 rest frame に対応させる。上顆をカメラで
計測した値ではなく、公開モデルの一般形状を利用したリターゲットである。

採用する source 値は GH→elbow=(.0061,-.2904,-.0123)、屈伸軸=
(.0494004,.0366003,.998108)、elbow→radius=(.0004,-.0115,.02)、
radius→wrist=(.018,-.242,.025)、回内外軸=(-.017161,.992666,-.119668)。
後二つの offset の和を尺骨中心線の neutral 方向に使い、外反角を消さない。
VRM の実測骨長を維持し、rest の軽い曲がりはこの neutral への固定変換で取り除く。
左側の位置は極性ベクトル、軸は軸性ベクトルとして反射する。

橈骨頭 offset `o` と橈骨から手根までの offset `w` を保持する。
回内外回転 R(φ) による手首方向を `nφ=normalize(o+R(φ)w)` とし、
neutral 方向 `n0=normalize(o+w)` からの実効回転を
`Qφ=arc(R(φ)n0,nφ) R(φ)` とする。単一 lowerArm には Qφ を写し、
手首までの半径だけを authored forearm length に固定する。橈骨の向きと
offset による横方向運動を残すが、橈尺骨を別々の二本の表示骨としては扱わない。
独立した hand twist、可変長、回旋の折半は追加しない。

FK は上腕→斜め肘軸の屈伸→この橈尺関節の実効回転→手首2軸の順。
IK も同じ u·R(h,f)v=A cos(f)+B sin(f)+C から屈伸を解き、理想蝶番の
cosine rule を前提にしない。ほぼ伸展した三角形は倍精度で解き、最終の位置は
FK だけが生成する。肘・手首の計算位置を別値で上書きしない。

## 肩甲帯 (#252)

肩甲帯は [De Sapio et al. ICRA 2006](https://ai.stanford.edu/manips/publications/pdfs/DeSapio_2006_ICRA.pdf)
の Table I / Eq.9 と Maier 2024 supplement B.1 を照合し、SC protraction/elevation と
AC internal/upward/tilt の5角を、胸郭基準の挙上面・挙上角から計算する。
係数は `girdle::rhythm` にまとめ、任意の比率で肩や肘へ配らない。
MyoArm の phantom inverse joints と同じく、SC の向きは AC の位置を運ぶが、
AC の胸郭に対する向きへ二重継承しない。

VRM shoulder の SC→GH の長さは不変。MyoArm の二リンクが生成する GH の
方向を authored SC→GH の球面に写す。二リンクの半径変化は VRM の単一肩
リンクでは表現せず、骨を追加・伸縮しない。sourceのarm-downではなく、VRMの
実際のauthored T/A姿勢におけるrhythmを基準として方向を合わせる。
上腕は胸郭に対する絶対角で解き、
local delta へ変換するときに解いた肩回転を一度取り除く。

観測胸郭は校正時と現在の左右肩・左右股関節の4点を、股関節中点原点で
Kabsch の最小二乗回転へ合わせる。肩だけから胸郭を定義すると肩の前出しを
全部消してしまうため、4点の fit 後の肩残差を現在胸郭軸で保持する。
純粋な剛体回転の残差はゼロ。前出しと胸郭変形の完全な分離は4点では不能で、
残差も GH の直接計測ではない。SC の2角を合わせる入力として扱い、未観測の
AC は公開 rhythm から推定する。モデルの neutral 肩幅で尺度を合わせる。
肩 trim と per-model profile は最終 bone 補正でなく、解決する目標に含める。

## CMU の記録による肩の連成領域 (#253)

PosePrior の非商用条件、Holden の実演データ由来である LAFAN1 の
CC BY-NC-ND 条件から、それらの学習済み領域を同梱しない。
[CMU Graphics Lab](https://mocap.cs.cmu.edu/) と
[FAQ](https://mocap.cs.cmu.edu/faqs.php) が商用製品への組込み・改変・再配布を
認める ROM 収録 74/13、126/14、127/02、143/21 を用いる。原データそのものの
転売は禁止。NOTICE に帰属と利用条件を残す。4 subject ID は4人を保証せず、
年齢・性別・関節の受動最大可動域もこの収録からは確定しない。

実装は Holden の [Joint Limits 951358f](https://github.com/orangeduck/Joint-Limits/tree/951358f73a90c82ff4fa33c6d11969c1eb0b02e1)
の full-rotation 26-DOP（MIT）。swing と twist を別々の範囲へ分解しない。
ASF の bone axis と AMC の自由度・XYZ 順から C M C^-1 を作り、radius の
屈伸軸と humerus の長軸が作る解剖学的 T 基準に移す。clavicle に相対の
humerus 回転を右側へ反射して集約する。26,386 side samples を13方向へ
射影した min/max を採用し、元の softening と任意の padding は加えない。
入力のハッシュと変換式は JSON / converter に残す。独自の生体係数ではない。

本番では解いた girdle と上腕の相対回転を同じ T 基準・主値の scaled-axis
へ変換し、全半空間を判定する。一定上腕方向でも軸回旋により判定が変わる。
これは収録範囲を近似する凸包状の許容領域であり、全人類の解剖学的最大範囲や
未収録組合せの医学的妥当性を保証するものではない。肘・橈尺関節の姿勢依存
軟部組織限界をこの肩データから推定したとはしない。そこには出典付きの固定
可動域と、実モデルの親子 FK・体表衝突を併用する。

静的 solve と途中経路は同じ判定を使用する。主値 chart の pi 境界も距離として
扱い、SO(3) log の微分ノルム上限 pi/2 から区間内判定の角度余裕を求める。
左右・非identity rest、独立 clamp なら通る不正な組合せ、自然立位が領域内に
あることを局所確認した。


## 表示形状と衝突 (#256)

VRM 0.xの衣装を含めた描画確認で、旧importのspring collider offsetに
左手系→glTF右手系のZ反転が欠けていることを確認した。
[three-vrm 1b4fc0c の _v0Import](https://github.com/pixiv/three-vrm/blob/1b4fc0cc7ef39a49d62bb7a66dcfeca8f65316f7/packages/three-vrm-springbone/src/VRMSpringBoneLoaderPlugin.ts#L284-L291)
と同じローカル変換をimport時に行う。モデルの正面を合わせるrootのY半回転とは
別の変換である。修正前にVRM 1.0へ変換済みの管理コピーには元形式の情報が
残らないため、この修正を適用する場合は元のVRM 0.xを再インポートする。

表示中のメッシュから、胸郭・上腕・前腕・手/指の骨と表示primitiveごとに凸包を作る。
翼・衣服・皮膚など別の表示パーツ間の空間を、一つの凸包で埋めない。
衣服も同じ対象とし、頭/脚の独立メッシュは上肢領域から除く。各三角形を、
3頂点の支配骨のすべての包に含めるため、領域境界の面が抜けない。
候補FKに対して元のskin weights / inverse bindを使い、各頂点をLBSで更新する。
同一の一骨がweight 1で動かす頂点群は、その凸包の内点だけをbind時に削除できる。
これはすべての候補で凸結合を保ち、近似誤差を増やさない。混合weightは残す。

凸包は凹みを埋める外包なので、衣服の空隙で必要以上に接触を判定しうる。
固定の胸厚や身体半径は使わない。隣接骨の重なりは、混合weight頂点と領域を
跨ぐ三角形から得た関節球内に限って許す。凸包同士の交差多面体の全頂点が
球内かを調べ、関節から離れた貫通を丸ごと免除しない。接触距離がちょうどゼロの
隣接形状も同じ関節接続として判定し、IKが構造上の接続を引き離そうとする状態を防ぐ。
同じ手の指間接触は
固定ポーズの責務として除外し、胸・反対腕/手との衝突を判定する。

[Parry 0.31.1](https://parry.rs/docs/user_guide/geometric_queries/)のf64版でGJK/EPAを使い、距離ゼロまたはEPAが接触深度を返せない場合は
凸多面体の面法線・辺の外積によるSATで接触と体積交差を区別する。正距離は
GJKの近似値をそのまま使わず、その法線への全頂点の射影から分離平面の下界を求める。
関節接続では、凸包の面方向ごとに元の全頂点を射影し、形状を外包する支持平面を作る。
ほぼ同一の端点群でできる極小三角形の面を、そのまま切断平面として使わない。
両包のAABBの共通部分を支持平面で順次クリップし、切断面も同じ多面体へ追加する。
経路の曲率半径は平面とAABBの外側へ加え、極小の膨張ごとに凸包を再構築しない。
この幾何計算は倍精度とし、同一辺の切断を同じ順序で評価して重複頂点を除く。
逐次平面クリップはSutherland–Hodgman方式で、
[Howlandの3D polygon clipping](https://www.cs.trinity.edu/~jhowland/cs3353/pclip/pclip/)にも照合した。
外側の球/AABBによる距離の下界は非貫通の証明に使う。静的IKへそれを
微分する距離制約として渡すと、実形状が離れていても包囲形状の接触が偽の境界となる。
各SQP反復で中心差分の刻み `f32::EPSILON.cbrt()*arm_length` より離れていると
証明できた組は不活性とし、残る組だけの距離と
関節接続の交差半径を実形状から微分する。この組を中心差分の両側で固定し、
候補の非線形評価では再選択して、新しく生じる接触も検査する。
包囲形状が重なっていても、実形状の距離・関節接続の余裕が同じ刻みより大きい
組は不活性にする。構造上離れている多数の面を差分する必要はない。
形状と骨変換は、実際に評価する組が必要になった時点で一度だけ更新する。
微分中に固定した不活性な組のために全skin頂点を再計算せず、経路検査で
最初の未分離の組を見つけた後も残りの形状を生成しない。
交差多面体を切り取る際は、現在のAABBが完全に内側にある面を飛ばし、
完全に内側の既存polygonをそのまま保持する。同じ半空間の積を計算し、
形状・関節接続球・非貫通条件を省略する近似は加えない。
許容する負距離は `64*f32::EPSILON*arm_length` の数値丸め分のみ。
表示用MorphWeights（直接値/参照先）を同じ頂点へ適用し、領域内の頂点を動かす
targetのweightが変わった場合は再bindする。顔だけを動かすtargetは再bindを起こさない。
形状変更は状態切替として再解決し、旧形状の経路証明を使い回さない。
制御腕以下のhelperは最寄りの制御骨へ集約し、それ以外の衣服helperは実際の
現在変換を使う。腕compositorはnode constraint/表情/spring boneの後に一度だけ
restの局所offsetとhelper階層から合成し、追加回転・伸縮を後段へ通さない。

## 両腕解決と時間更新 (#257/#258)

一つの候補は、左右の肩3角・肘・回内外・手首2角・SC2角・固定指ポーズを持つ。
肩甲帯のSC独立2角の範囲は、採用した二変数rhythmのp/e定義域上の包絡である。
これは独立に計測したSC受動限界ではない。未観測SCは同じ公開rhythmをpriorにし、
肩残差が得られる場合はその位置への目的を使う。ACはrhythmで決まる。

固定骨長FK、関節域、左右/胸との非貫通を同じ候補で評価する。
Gauss–Newton SQPで各距離不等式とROMを線形化し、正定値の数値LM項を含む
凸QPを非負双対座標反復で解く。LM項は関節制限を緩めない。バックトラックで
非線形の制約違反を観測残差より優先し、左右の18座標を同時に更新する。
ROMは各半空間を別々に線形化する。最小余裕だけを差分すると、境界の交点で
微分対象が切り替わり、許容方向への移動まで止まるためである。
接触境界の曲率を線形制約だけで扱うと、接線方向の改善stepまで棄却される。
[GouldのSQP講義](https://www.numerical.rl.ac.uk/media/people/nick-gould/part7.2.pdf)の
second-order correctionに従い、違反した境界の同じJacobianから最小ノルムの
法線補正をSVDで求める。補正後も全非線形制約と経路を再評価し、元のstepより
大きい補正や未解決の違反を受理しない。数値上の正の余裕は既存のf32丸め幅で、
人体可動域を緩める係数ではない。
保持姿勢とneutral側から同じ目標姿勢を解き、許容解のうち残差が小さい方を採用する。
通常のworkerは採用stepを4回まで進め、未収束の代替候補も次へ引き継ぐ。
棄却stepはtrustを数値停止幅まで縮めるので、batch境界で同じ棄却を繰り返さない。
姿勢が変わらないtrust縮小では同じJacobianを再利用し、採用stepでのみ破棄する。
代替候補が収束済みで目標が変わった場合だけ、neutralから探索を再開する。
現在の許容解を先に描画でき、遅い代替探索の完了待ちで腕を止め続けない。
未収束の場合は観測を保持したtickでも反復を継続する。現在解が許容範囲内なら、
FKの目的誤差が改善しない候補は衝突形状を生成する前に棄却する。
観測できる手首・肘・掌を目的に使う。欠測した手首/肘はneutral FKへ戻し、
掌欠測は前腕回旋・手首の局所座標をneutralへ戻すpriorとする。掌を空間の
neutral方向へ固定して観測された腕の挙上を妨げる目的は置かない。
仮想腕のpoleは観測された肘点と混同せず、解析IKで肘位置の意図へ変換する。
姿勢解決の後に肩clamp、shoulder trim、再IK、掌合わせは実行しない。

`Feasible { residual, converged }` は制約内の局所解であり、残差ゼロとは限らない。
初期/形状変更の解決中は `Solving` とし、認定前のA/T poseを表示しない。
通常更新でも許容領域へ戻す反復が進行中なら `Solving` とし、直前の認定姿勢を保持する。
予算内に許容解が見つからない場合は `NoFeasibleSolution`、形状不足は
`InvalidGeometry`、経路を証明できない場合は `BlockedPath` として既存診断へ渡す。
これらは大域的な解の不存在を証明したという意味ではない。

許容状態の間は関節座標上の線分を `10t³−15t⁴+6t⁵` で進み、端点速度と加速度を
ゼロにする。途中の観測変更は進行中のsegmentを初期化せず次の目標へ渡す。
各区間でSO(3) logとskin頂点の2階微分上限を求め、端点凸包を
`M*(区間長)^2/8` だけ膨張した包とROMの余裕で区間全体を判定する。
ROMの各境界には、端点余裕の線形補間から `M*t*(1-t)*(区間長)^2/2` を
引いた二次式の最小値を使う。境界から離れる区間の端点に、中央で最大となる
誤差を一律に課さない。ROMを証明できない区間、または最初の未分離の形状対を
見つけた区間は、その時点で分割する。残りの形状対を調べても受理できないためである。
関節接続はそのpivotに対する移動座標で囲み、pivotの曲率分も加算する。
指は一つのdigitの親子回転だけを継承し、他の指の運動を加算しない。掌自体の
軌跡に指の回転は加算せず、混合skin weightsを通じた実際の影響だけを含める。
4指のMCP開閉はrestの開き角を一定の枝で引く。毎回の角度差をatan2で±piへ
折り返してからweightを掛けると、部分weightで反転が生じるため、その経路は使わない。
主値chartのpi境界を跨がないことも別に確認する。連続包の分離は非負を要求し、
実際のf32 FK表示には前述の丸め許容だけを使う。SQPの目標にはその4倍の正の
数値余裕を置く。これは衣服の厚みや生理的なsoft limitではない。
二分割の計算予算を使い切った区間は受理せず、経路探索の辺としても使わない。
端点だけの検査やslerp後のclamp、未証明の迂回や姿勢飛びは用いない。

交差した腕を開く際、厚い袖同士の複数接触で局所SQPが止まる例をInoreで確認した。
解いた目標まで直線の関節経路を証明できない場合は、
[Kuffner & LaValle, RRT-Connect (ICRA 2000)](https://www.kuffner.org/james/papers/kuffner_icra2000.pdf)
の双方向探索で接続する。18関節座標とbody/指ポーズの補間進行率を探索し、
木の各辺とshortcutにも同じ連続区間証明を使う。正規化座標のstepと探索回数は
計算予算であり、人体可動域や衝突の許容幅を追加するものではない。
探索点は先にFKとROMを判定し、不正な点のskin生成を省く。点の衝突検査も
最初の違反で打ち切り、通過した点同士の辺を連続区間証明へ渡す。
認定した折れ線の各区間に同じquinticを適用し、接続点で速度と加速度をゼロにする。
同じ端点対のshortcut証明は再試行しない。特に3点経路に残る唯一のshortcutは、
探索開始時に拒否した始点から終点への直線なので再検査しない。
探索失敗はBlockedPathのまま返し、別のIK枝へ瞬間移動しない。

体幹の新しい姿勢だけを先に適用すると、進行中の腕経路へ身体が入り得るため、
衝突に関係するbody local poseと頭/首の親回転補償も同じsegmentの進行率で移す。
回転は固定軸のexp/log補間で、一定のlocal offsetとscaleを保つ。body FKも現在の
胸郭を除いた同じ座標で評価する。頭の並進から観測胸郭へ追加のleanは掛けない。
表示したbodyを翌tickのanimation baseに採用せず、上流bodyを復元してから
接地の補正前姿勢とtorso leanを復元する。脚の接地補正を累積しない順序を固定する。
短い回転のFKにはidentityへの角度deadbandを持つarcを使わず、倍精度の
`normalize([from×to, 1+from·to])` を用い、反平行の未定義点はOptionで返す。
解決と経路証明はBevyのAsyncComputeTaskPoolで行い、認定した経路の終点から次の
stepを先行計算する。終点が外部変更で失われた結果は接続しない。描画側は
検証済みのsegmentと実際に使った観測seqを保持する。
同じ目標・body姿勢が新しいseqで届いた場合は、認定済みの解を再利用してseqだけを
更新する。worker待ち・経路の進行中は、表示側のconvergedをtrueにしない。
中心差分の列と独立した経路区間は、既存のComputeTaskPoolで並列に評価する。
描画tickではこの認定済み経路のパラメータとFKだけを更新し、同じ形状クリップを
繰り返さない。形状変更時は既存の再bindで経路を破棄する。
