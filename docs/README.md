# 再発防止
このフォルダは本ファイルだけ・最大10行。説明・履歴・検証記録を増やさず、削除内容を他所へ移さない。
- GNMはMediaPipe directを上回らず瞬きも失ったため撤去済み。実験backendや推測の対応表を復活させない。
- MediaPipeの瞬き値は閉眼でも1に届かない。閉眼確定後の1.0を平滑化・欠測復帰・書込epsilonで弱めない。
- 同じカメラseqでも描画tick間の減衰状態を保持する。頭と肩では誤差・微分の座標系が違い、時定数と半減期も交換不可。
- 脚の完全伸展付近で外積から曲げ軸を再生成すると180度反転する。腕の外反角を持つ三角形の法線と固定ヒンジ軸も混同しない。
- 脇を締めるため上腕と胴体の重なりは許容する。肘を含む前腕・手は胴体との衝突と経路途中の貫通を検査する。
- 掌の単位方向誤差を腕位置誤差へ直に足すと、掌回旋で腕全体が動く。実寸の掌マーカーで尺度を合わせる。
- 急変判定は前回の有効な観測との比較。最後に採用した位置との比較を続けると、安定した新位置にも復帰できない。
- 表示60fpsでも腕入力は数Hzに停滞し得る。毎回のskin凸包再計算・区間ごとの150ms停止応答・同一観測での反復増量を戻さない。
